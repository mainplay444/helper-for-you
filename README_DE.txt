TOOLBOX — DEUTSCHE VERSION

Dateien:
- index.html  Hauptseite und Oberfläche
- style.css   Design, responsive Layout und helle/dunkle Darstellung
- script.js   Interaktionen und Werkzeuge

LOKAL STARTEN
1. Alle drei Dateien im selben Ordner lassen.
2. index.html im Browser öffnen.

AUF GITHUB PAGES VERÖFFENTLICHEN
1. Erstelle ein GitHub-Repository.
2. Lade index.html, style.css und script.js (optional auch diese README) in den Repository-Hauptordner.
3. Öffne Settings > Pages.
4. Wähle Deploy from a branch, den Branch main und den Ordner /(root), dann Save.
5. Warte, bis GitHub Pages die Website veröffentlicht hat.

ENTHALTENE WERKZEUGE
Zufallsrad, Passwortgenerator, QR-Code-Generator (QR-Versionen 1–4, Fehlerkorrektur L; kurze Texte bis ca. 78 UTF-8-Bytes), Farb-Generator, Taschenrechner, Zufallszahl, Würfel und Münze, Timer und Stoppuhr, Nickname-Generator, Ideen-Generator, Textzähler, Einheiten-Umrechner, CSS-Verlauf und Notizblock.

HINWEISE
- Die Website braucht keinen Build-Schritt.
- Passwörter werden im Browser erzeugt und nicht an einen Server gesendet.
- Favoriten, Thema und Notizen werden lokal im Browser gespeichert.
- Der QR-Generator ist bewusst auf QR-Versionen 1 bis 4 beschränkt, damit kein externer QR-Dienst nötig ist.
- Das Design lädt DM Sans und Space Grotesk von Google Fonts; falls offline, verwendet es System-Schriftarten als Fallback.
